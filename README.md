# LLM4ChipDesign

LLM4ChipDesign is a consolidated repository of projects exploring the use of **Large Language Models (LLMs) in digital chip design**, verification, and hardware security. The work focuses on applying LLMs to automate and assist **RTL generation, functional verification, prompt engineering, and Trojan/security analysis**.

---

## Repository Organization

This repository is organized into **module-level parent folders**, where each folder contains the complete work related to that module, including experiments, scripts, results, reports, and documentation.

### Top-Level Modules

- `ChipChat/` – LLM-assisted RTL design and interaction framework  
- `AutoChip/` – Automated RTL generation and evaluation using LLMs  
- `Veritas/` – LLM-based hardware security and Trojan detection analysis  
- `VeriThoughts/` – Reasoning-driven verification workflows using LLMs  
- `Hierarchical Prompting/` – Structured prompting strategies for hardware tasks  
- `GHOST/` – Hardware-oriented security and analysis experiments  

---

## Final Project Presentations (For Evaluation)

The **final project presentation files** required for evaluation are located **inside the parent folders** of the following modules:

- **ChipChat** → `ChipChat/`  
- **AutoChip** → `AutoChip/`  
- **Veritas** → `Veritas/`  

Each of these folders contains the **final presentation summarizing the project objectives, methodology, experiments, and results**.

---

## Project Work Location

All project-related materials are stored within their respective module folders.  
This includes:
- Source code and scripts  
- Prompting strategies and logs  
- Experimental results and evaluation artifacts  
- Reports and documentation  
- Final presentation files (where applicable)

Each module can be evaluated **independently** by navigating to its corresponding directory.
